# Update 5 — Rise of Legends: audit, plan and checklist

`[x]` = implemented and verified (test or real browser check); `[~]` = implemented, partly verified; `[ ]` = not done.

## 1. Phase 1 audit (baseline commit 505650a = the Update 4 delivery)

Editable TypeScript source exists (Vite 7 + TypeScript strict + Canvas 2D + Vitest); the single-file HTML is generated by `npm run build:single`, so all work happens in `src/`.

Verified in the code (not assumed from earlier briefs):
- **Screens**: Home, Play (Rush / Sky Trials / Arena tabs), Dragons (collection with search, rarity/element/ownership filters, five sorts, Dragons/Eggs tabs; inspector Overview/Growth/Compare/Mastery/Style/Records), Dragon Observatory dialog (side/top views, poses, stage and marking previews, zoom/pan, screenshot, egg page), Hatchery (reel, staged hatch, Quick reveal, Open 5, odds/history/Essence catalog), Journal, Settings (Audio / Accessibility / Performance), results screen with an evolution moment.
- **Modes**: Dragon Rush (60 s; 120 s Expeditions after 10 flights), Sky Trials (12 courses, normalized level-1 stats, medals), Dragon Arena (top-down, 4 waves, elite, Stormcrown Wyrm boss, upgrade breaks, endless continuation). **The newest mode is Dragon Arena** — no later mode exists.
- **Roster**: 24 species, stable ids, in `src/content/species.ts` (Fire: Ember, Cinder, Pyrelisk, Solpyre · Water: Tide, Ripple, Abyssfin, Leviara · Nature: Grove, Bramble, Orchid, Rootwarden · Air: Gale, Zephyr, Cloudtail, Tempest · Frost: Rime, Snowcap, Frostfang, Glacielle · Storm: Spark, Voltwing, Thundercrest, Astralux). Six body families, four evolution stages (hatchling 1, juvenile 5, adult 15, elder 30). Per-species art table in `src/render/speciesArt.ts`.
- **Rarity**: Common 55 %, Rare 28 %, Epic 14 %, Legendary 3 % (`HATCHERY.odds`), equal chance within a tier; pity: 10th egg without Epic+ → Epic/Legendary 14:3, 40th without Legendary → Legendary. Duplicates → Essence 10/25/60/150. Direct Essence unlocks 40/100/240/600.
- **Progression**: levels 1–30, XP from active play and feeding (20 fruit = 100 XP), talents at 10/20, mastery (3 per species), markings, titles.
- **Hatchery**: outcome drawn with crypto RNG and saved in one transaction before the reel; recovery of unrevealed openings; 24 designed eggs with fractures (Update 4).
- **Persistence**: save v3 in localStorage with backups, idempotent sanitize/migration, protection for newer saves, export/import.
- **Rendering**: fixed 1280×720 stage scaled to the window; Canvas 2D renderers; cached backgrounds; bounded caches keyed by art revision.
- **Update 4 items present**: richer species art and eggs, Observatory, Egg Codex, collection tools, rendering/UI polish — all exist and are kept.

## 2. Save safety for Update 5
Save stays **v3**; new fields are optional and default when absent (sanitize is idempotent): `prefs.lastMode`, `prefs.dismissedGoal`, `prefs.tutorials`, `settings.screenShake`, `ascent` records (best / bestAssist / runs / bestRegion). Existing dragons, levels, mastery, favorites, unlocks, resources, settings and hatch history are untouched. Odds, pity, costs and duplicate conversion are unchanged.
